# A320 MCQ Trainer

A mobile-first web app for practising A320 Technical Systems multiple-choice questions. Designed for iPhone use via browser or "Add to Home Screen".

## Features
- 516 questions across 16 ATA chapters
- **Practice mode** — tap an option, move to next
- **Exam mode** — select answers silently, get a summary at the end
- Filter by chapter
- Review session answers after each quiz
- Works offline once loaded (PWA)

## Deploy to Vercel

1. Push this repo to GitHub
2. Import the GitHub repo in [vercel.com](https://vercel.com)
3. Deploy — no environment variables needed

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) on your phone or browser.
